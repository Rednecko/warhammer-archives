# Battle record template

<div class="archive-page-label">Living campaign · Editorial form</div>

This page is a reusable **Markdown template** for each real tabletop battle. Copy it into a new file when a game is played; do not publish example outcomes as if they happened.

```markdown
# [Battle title]

**Record ID:** SS-B001
**Played on:** [date]
**War zone:** [planet / region / theater]
**Opponent:** [army or player-designated force]
**Game format / points:** [details]
**Mission:** [mission name]
**Result:** [win / loss / draw]
**Status:** Played and recorded

## Forces committed

- Sons of Sigismund: [units and named participants]
- Opposing force: [known units or characters]

## The engagement

[Short factual game account: deployment, pivotal turns,
heroic actions, reversals and the outcome.]

## Losses and honors

[Only casualties, honors and promotions we elect to
preserve as lore; not every destroyed game model must
be a permanent death.]

## Recovered artifacts

[None, or agreed named items with provenance]

## Lasting consequences

[Changes to oath roster, relations, relic register,
ship or future campaign plans.]

## Supporting material

[Miniature photos, mission sheet and optional narrative.]
```

## Recording rules

- Only played games or explicitly approved narrative events become history.
- A game loss need not mean the order has ceased to exist.
- A model removed from the table is not automatically a permanently dead named character.
- Every new relic or promotion must agree with the established personnel and relic registers.
- Preserve the difference between **what happened at the table** and **how we later narrate it**.
