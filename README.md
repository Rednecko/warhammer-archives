# Warhammer Archives

Public Warhammer 40,000 lore wiki; only authorized GitHub collaborators can edit.

**Website after publishing:** https://rednecko.github.io/warhammer-archives/

Built with MkDocs Material and GitHub Pages. Markdown articles live under `docs/`; navigation is in `mkdocs.yml`.

## First-time publishing

Open **Settings → Pages → Build and deployment** and set **Source** to **GitHub Actions**. Open **Actions → Publish Warhammer Wiki** to see build status; rerun the workflow if necessary.

## Editorial policy

Preserve approved lore, clearly mark open or provisional details, and never invent tabletop results.
